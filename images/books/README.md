# Book cover artwork — drop files here

Place the final cover images in this folder. Filenames must match `js/books-config.js`.

| File | Used for | Suggested size |
|---|---|---|
| `memoir-paperback-cover.jpg` | Paperback product card + hero | 1000×1500 (2:3) |
| `memoir-hardcover-cover.jpg` | Hardcover product card | 1000×1500 (2:3) |
| `workbook-cover.jpg` | Workbook product card + hero | 1000×1500 (2:3) |
| `combo-cover.jpg` | Combo product card | 1200×800 (3:2) |
| `og-books.jpg` | Social share preview | 1200×630 |

Until files are added, the storefront shows a tasteful "Cover artwork coming soon" placeholder.
Optimize images (JPG/WebP, compressed) before uploading. Keep the exact filenames or update the paths in `js/books-config.js`.
